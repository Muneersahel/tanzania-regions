# Changelog

All notable changes to the `tanzania-regions` library will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Comprehensive documentation for the library
- JSDoc comments for all exported functions and interfaces
- TypeScript type definitions
- Usage examples for React, Vue, and Node.js
- Enhanced package.json with better description and keywords

### Changed
- Improved README with detailed API reference
- Updated function documentation with examples

## [0.0.1] - Initial Release

### Added
- Core library functionality
- `regions()` function to get all Tanzania regions
- `districts(region)` function to get districts for a specific region
- `wards(region, district)` function to get wards for a specific district
- Complete data for all 31 Tanzania regions
- Data for 185+ districts
- Data for 3,900+ wards
- TypeScript support with full type definitions
- Zero dependencies
- URL-friendly slugs for all locations

### Data Coverage
- All 31 regions of Tanzania
- Complete district coverage for each region
- Complete ward coverage for each district
- Accurate location names and slugs
